# Database Migrations

Alembic is the schema-change mechanism for new database revisions. The first
revision, `20261011_0001`, is a marker for the existing SQLAlchemy schema. It
intentionally performs no DDL and has no destructive downgrade.

## Existing database

Before adopting the baseline, compare the configured database schema with
`app/database/models.py`. Do not run `alembic stamp` until the schema is
confirmed to match the pre-tenancy schema. Stamping records the baseline
revision; it does not alter tables or rows. Then apply the additive organization,
session, and industry-profile migrations after verifying the target and backup.

```powershell
python -m alembic stamp 20261011_0001
python -m alembic upgrade head
```

## Fresh database

Create a fresh schema from the reviewed migration chain. Revision 1 builds the
legacy schema; later revisions backfill organization ownership, add auth
sessions, and seed the four industry profiles.

```powershell
python -m alembic upgrade head
```

## Future revisions

Create a revision, review its generated operations, and apply it only after
backing up and verifying the target database:

```powershell
python -m alembic revision --autogenerate -m "describe schema change"
python -m alembic upgrade head
```

Autogenerated revisions are proposals and must be reviewed for data-preserving
backfills, constraint order, and rollback behavior. No migration has been
applied to the configured database as part of this implementation.

## Authentication configuration

Set `REROUTE_SECRET_KEY` to a unique random value with at least 32 bytes of
entropy. Do not commit it. Refresh tokens are issued only in an HttpOnly,
SameSite=Strict cookie; HTTPS deployments use the secure cookie default. For
local HTTP development only, set `REROUTE_COOKIE_SECURE=false` in the local
environment.

After creating the schema, run `python scripts/create_admin.py` once to create
an organization and its initial administrator. The command prompts for the
password without echoing it. It does not reset or overwrite existing accounts.
